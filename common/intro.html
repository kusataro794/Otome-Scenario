COMMON ROUTE / INTRODUCTION

いつも通りの、
朝だった。

BEFORE THE BORDER CHANGES

結衣、玲央、湊。
三人にとって当たり前だった日常と、
まだ名前のついていない感情を描く導入編。

近すぎるから、見えないものがある。
近づけないから、言えないものがある。

SCENE 01

朝 ―― いつもの二人

水城家・結衣の部屋〜リビング / 07:08

四度目のアラームを止めたところまでは覚えている。

五度目が鳴らないのは、私がようやく起きたから――ではなかった。

玲央

「姉さん。七時八分」

扉の向こうから聞こえた声で、私は薄く目を開けた。

結衣

「……起きてる」

玲央

「それ、寝てる人の返事」

「入るよ」

水城玲央。十八歳。

幼い頃、両親の再婚で家族になった、私の一つ下の義弟。 血は繋がっていないけれど、もう十年以上一緒にいる。

玲央はカーテンを開けると、机の上から学生証を拾い、充電器と一緒に私の鞄へ入れた。

玲央

「一限、間に合わなくなるよ」

結衣

「……一限？」

三秒。

結衣

「――一限！」

飛び起きた瞬間、毛布に足を絡ませる。

床へ行くはずだった身体を、玲央の腕が止めた。

玲央

「危ない」

結衣

「……玲央、神」

玲央

「毎朝こうなら、僕がいないと生きていけないね」

結衣

「それはさすがに言いすぎ」

「……たぶん」

玲央が笑った。

朝食も、忘れ物も、私がなくしそうなものも。 玲央は、私よりよく覚えている。

昔からそうだったから。

私はそれを、特別なことだとは思っていなかった。

演出情報を見る

狙い：結衣の天然・生活面のポンコツさと、玲央の自然すぎる世話焼きを最初の数分で定着させる。

玲央：鞄へ触る行為は不穏に見せすぎない。現時点では「ずっとこうしてきた弟」。

伏線：玲央は結衣の予定・持ち物を把握している。それが後の確認癖へ連続していく。

SCENE 02

約束 ―― 玲央が覚えていること

水城家・リビング / 07:32

テーブルには、トーストと目玉焼きとカフェオレ。

私が作ったら、たぶん目玉焼きではなく「フライパンに張りついた何か」になる。

結衣

「玲央って、本当に何でもできるよね」

玲央

「姉さんが何もしなさすぎるだけ」

結衣

「失礼な」

言い返しながらトーストをかじる。

ふと、昨日友達とした一人暮らしの話を思い出した。

結衣

「私も、そのうち一人暮らしとかしてみたいなあ」

玲央の手が止まった。

玲央

「……姉さんが？」

結衣

「その反応なに」

「すぐじゃないよ。大学生のうちに一回くらい、ってだけ」

玲央

「やめた方がいいと思う」

結衣

「即答！？」

玲央

「鍵なくす。料理できない。朝起きない」

「知らない人にも普通に道教えようとして、気づいたら十分くらい話してる」

結衣

「最後は親切心じゃん」

玲央

「危機感がないって言ってるの」

いつもより少しだけ強い声。

私は玲央の顔を見る。

怒っている、というより。

一瞬だけ、本当に困ったように見えた。

結衣

「……玲央」

玲央

「なに」

結衣

「そんな心配しなくても、いきなりいなくなったりしないよ」

「玲央もさ、もっとわがまま言っていいんだからね」

玲央が、瞬きをした。

その言葉だけが、何かに触れたように。

MEMORY / REO 十年前

A MEMORY HE NEVER FORGOT

再婚して間もない頃。

小さかった玲央は、人と話すのが苦手で、泣き虫で。 新しい学校でもうまく馴染めなかった。

放課後。数人に囲まれて、何も言い返せずにいた玲央の前へ。

膝を震わせながら、それでも結衣は立った。

幼い結衣

「玲央くんが嫌だって言ってるでしょ」

結衣だって、怖かった。

声は少し震えていた。

それでも、逃げなかった。

帰り道。 泣いたことを恥ずかしがる玲央に、結衣は首を傾げた。

幼い結衣

「弱いのって、そんなにダメ？」

「玲央くんは玲央くんじゃん」

幼い玲央

「……迷惑じゃない？」

幼い結衣

「なんで？」

「もっとわがまま言っていいよ」

「だって、家族なんでしょ」

そして。

幼い結衣

「大丈夫。ずっと一緒にいるから」

玲央にとって。

あの日の言葉は、子どもの気休めではなかった。

初めて、自分を選んでくれた人の約束だった。

POINT OF VIEW YUI
玲央

「……覚えてないくせに」

結衣

「え？」

玲央

「何でもない」

玲央はいつもの顔で笑った。

玲央

「一人暮らしの話は、また今度ね」

なぜ「また今度」なのかは分からなかったけれど。

時間がなかったので、私はそのまま頷いた。

演出情報を見る

最新設定反映：玲央にとって結衣は、弱かった自分を怖がりながらも守ってくれた「最初のヒーロー」。

重要語：「もっとわがまま言っていい」「玲央くんは玲央くん」「ずっと一緒にいる」。後の確認癖・特別でいたい欲求・依存の根に置く。

結衣：普段の天然さと対照的に、本当に誰かが傷ついている場面では迷わず踏み込める人格を、過去から一貫させる。

SCENE 03

通学路 ―― 待っている人

住宅街〜駅 / 07:48

家を飛び出すと、門の少し先に見慣れた背中があった。

結衣

「湊！」

朝倉湊。二十歳。大学二年生。

隣の家で育った、物心ついた頃からの幼馴染。

湊

「遅い」

結衣

「待ってた？」

湊

「別に。お前が来なきゃ先行くつもりだった」

結衣

「何分？」

湊

「十五分」

結衣

「めちゃくちゃ待ってるじゃん」

湊

「俺が勝手に待ってただけ」

湊はそう言って、私の鞄を持つでもなく、急かすでもなく歩き出す。

私が横へ並ぶのを、当たり前みたいに待っている。

湊

「一限だろ」

結衣

「なんで知ってるの？」

湊

「先週、自分で言ってた」

結衣

「みんな私の予定、私より覚えてない？」

湊

「お前が忘れすぎ」

玲央と似たことを言う。

でも、不思議と同じには聞こえなかった。

玲央は私の忘れる前に、必要なものを鞄へ入れてくれる。

湊は、私が忘れたら呆れて、それでも隣で待っている。

どちらも昔から変わらない。

だから私は、その違いについて考えたことがなかった。

演出情報を見る

対比：玲央＝先回りして生活へ入る。湊＝本人の行動を待ち、必要なら支える。

湊：「待ったこと」を恩に着せない。これが純愛ルート側の行動原理になる。

SCENE 04

大学 ―― 気づくときだけ

大学・講義棟 / 13:12

昼休み。

友人と話しながら歩いていた私は、危うく案内板へ正面からぶつかりそうになった。

友人

「結衣、前！」

結衣

「……おお」

友人

「何でその反応で済むの」

自分でも、ぼんやりしすぎだとは思う。

でも。

隣の友人が笑ったあと、ほんの一瞬だけ唇を噛んだのは見えた。

さっきまで届いていたメッセージ。 伏せたスマートフォン。 無理に明るくした声。

結衣

「……ねえ」

友人

「ん？」

結衣

「今日、このあと時間ある？」

友人

「あるけど。どうしたの？」

結衣

「何かあったでしょ」

友人の顔が止まった。

友人

「……なんで分かったの」

結衣

「分かんない」

「でも、笑い方いつもと違う」

友人は「大丈夫」と言った。

だから私は、首を横に振った。

結衣

「大丈夫じゃない人の大丈夫って、あんまり信用しないことにしてる」

友人

「……重いって思わない？」

結衣

「何が？」

「弱ってるときに誰かに頼るの、別に格好悪くないじゃん」

数秒後。

友人の目から、ぽろっと涙が落ちた。

私は慌てて鞄を探る。

結衣

「ハンカチ……あれ、ない」

友人

「締まらないなあ、もう」

泣きながら笑われた。

私は、少し安心した。

少し離れた廊下の端で、その様子を見ていた湊は何も言わなかった。

ただ、あとで私にポケットティッシュを一つ投げて寄越した。

湊

「昔からそうだよな、お前」

結衣

「何が？」

湊

「……そういうとこ」

また説明になっていない。

私は首を傾げた。

湊は、それ以上言わなかった。

演出情報を見る

主人公コア：結衣は普段は天然で頼りないが、誰かが本当に傷ついているときだけ異様に察しがよくなる。

価値観：弱さを馬鹿にしない／本人が「大丈夫」と言っても必要ならそばにいる。

湊：その性質を昔から知っている。だから好きになった理由を説明せずとも読者に伝える。

SCENE 05

恋の話 ―― 近すぎる二人

大学・カフェテリア / 16:35

放課後。

いつの間にか話題は、恋人がいるとか、好きな人がいるとか、そういう話になっていた。

結衣

「現実の恋愛、難しすぎない？」

「乙女ゲームみたいに選択肢出してほしい」

笑われる。

その流れで「結衣は好きな人いないの？」と聞かれた。

結衣

「うーん……いない、かなあ」

「幼馴染いるじゃん」と言われ、私は反射的に笑った。

結衣

「湊？　ないない」

「あれはもう、友達っていうか……生活の一部？」

我ながら雑な分類だった。

でも、本当にそれ以上の考えが浮かばない。

玲央はもっと簡単だ。

家族。

弟。

私を誰よりよく知っている、大切な家族。

机の上で、スマートフォンが震えた。

湊 → 結衣 まだ大学？
帰るなら駅いる。

ほぼ同時に、もう一件。

玲央 → 結衣 今日、何時に帰る？
晩ごはん作るから、分かったら教えて。

並んだ二つの通知を見て、友人が笑った。

友人

「十分愛されてるじゃん」

結衣

「そういうのじゃないって」

私も笑った。

本当に、そういうのではないと思っていた。

演出情報を見る

通知の対比：湊は「帰るなら」と選択を残す。玲央は帰宅時間を確認し、生活へ組み込む。

結衣：恋愛に鈍いのではなく、二人が近すぎて恋愛カテゴリへ入っていない。

SCENE 06

帰り道 ―― 言わない人

駅前〜住宅街 / 18:09

駅へ着くと、湊は改札の外にいた。

結衣

「待った？」

湊

「十分」

結衣

「また待ってる」

湊

「だから、俺が勝手に待ってるだけだって」

それ以上、何も要求しない。

一緒に帰ろうとも、早く来いとも。

ただ、来たら隣を空けている。

結衣

「今日、友達に湊のこと聞かれた」

湊

「何て？」

結衣

「好きじゃないの、って」

湊の足が、ほんの少し遅くなった。

湊

「……で？」

結衣

「ないない、って言った」

一拍。

湊

「そっか」

それだけだった。

笑いもしない。

怒りもしない。

ただ、いつもより少しだけ前を向いて歩いた。

家の近くまで来たところで、湊が私を呼び止めた。

湊

「結衣」

結衣

「ん？」

何か言いかける。

でも。

湊

「……いや」

「まだいい」

結衣

「何が？」

湊

「お前が分かんないなら、今言っても仕方ない」

結衣

「え、何それ。気になる」

湊

「気にしとけ」

湊は、笑った。

私が答えを出す前に、答えを押しつけない。

それが湊の優しさなのだと。

このときの私は、まだ知らなかった。

演出情報を見る

湊の核：結衣の選択を奪わない。好きだからこそ、本人が気づいていない状態で答えを迫らない。

弱点：尊重と自己犠牲が紙一重。「まだいい」が積み重なり、EVERYDAY以降で我慢が限界へ近づく。

SCENE 07

夜 ―― いつも通りのままで

水城家・リビング / 19:16

結衣

「ただいまー」

玲央

「おかえり、姉さん」

キッチンから玲央が顔を出す。

私の姿を見たあと、視線が一度だけ玄関の外へ向いた。

玲央

「湊さんと帰ってきた？」

結衣

「うん。駅にいたから」

玲央

「そっか」

笑顔。

いつも通りの。

夕飯を食べながら、今日の恋バナの話をする。

結衣

「好きな人いないのって聞かれてさ」

玲央の箸が止まった。

玲央

「姉さん、好きな人いるの？」

結衣

「いないよ」

玲央

「本当に？」

結衣

「何、その確認」

「いないってば」

玲央は、ゆっくり息を吐いた。

玲央

「……よかった」

結衣

「だから何が？」

玲央

「変な人に捕まってなくて」

結衣

「玲央、心配性すぎ」

朝の話を思い出して、私は笑う。

結衣

「一人暮らししたら、毎日電話してきそう」

玲央

「毎日で足りる？」

結衣

「え？」

玲央

「……冗談」

玲央は笑った。

私も笑った。

そして、ふと思い出したように玲央が聞く。

玲央

「姉さん」

「昔、僕に『ずっと一緒にいる』って言ったの、覚えてる？」

少し考える。

結衣

「……あー」

「なんか言った気がする」

玲央の目が、わずかに細くなる。

結衣

「でも、別に今も変わってないよ」

「玲央が本当に困ってたら、私は玲央の味方するし」

玲央

「……僕だから？」

結衣

「玲央だから」

迷う理由なんてなかった。

玲央は家族で。

私にとって、大切な弟なのだから。

玲央はしばらく何も言わなかった。

それから、とても嬉しそうに笑った。

玲央

「そっか」

その笑顔を見て。

私は、ちゃんと伝わったのだと思った。

POINT OF VIEW REO

姉さんは、覚えていない。

もっとわがままを言っていいと言ったことも。

ずっと一緒にいると言ったことも。

きっと、あの日の自分がどれだけ救われたかも。

それでも。

今も同じことを言う。

「玲央だから」と。

なら、俺が特別だって思っていてもいいよね。

湊の名前を思い浮かべる。

昔から姉さんの隣にいる人。

姉さんが信頼している人。

そして。

いつか、姉さんを自分から連れていくかもしれない人。

胸の奥が、静かに冷える。

玲央

「……大丈夫」

まだ、姉さんは何も知らない。

俺がどれだけ見ているのか。

何を確認してしまうのか。

誰が姉さんの隣にいるだけで、こんなにも嫌なのか。

知らなくていい。

まだ。

POINT OF VIEW YUI

夜。

明日の準備をしていた私は、鍵を鞄の内ポケットへ入れた。

入れた――つもりだった。

そして。

明日も今日と同じように、朝が来るのだと思っていた。

◇

家族だから、近くにいる。

幼馴染だから、隣にいる。

その境界を疑う理由なんて、まだ何もなかった。

演出情報を見る

玲央：現在の「確認癖・特別でいたい・嫉妬」の種を明示。ただしINTROでは行動を決定的な加害へ進めない。

一人称：表向きは「僕」。内面深部では「俺」を使い、外側の優しい弟と内側の欲望に小さな段差を作る。

INCIDENT接続：最後に「鍵を入れたつもり」を置き、次章『なくした鍵』へ自然につなぐ。

◇

INTRODUCTION END

――いつも通りの、朝だった。

近すぎるから、まだ恋には見えない。
大切すぎるから、まだ言葉にはできない。

三人の「いつも通り」は、
次の朝から、少しずつ形を変え始める。
